# Static Voxel GI

The indoor scene voxelizes the static `Library` glTF model once into one 64³
`R16G16B16A16_FLOAT` volume. The voxel pixel shader writes opacity and
material radiance from a small environment fill, plus the glTF emissive factor
and texture. Dynamic lights do not enter the volume. Mipmaps are generated
after the bake. The deferred lighting shader traces five cones per visible
pixel and adds the result to diffuse lighting.

Open the **Voxel GI** section in the indoor scene debug UI to adjust strength
and the emissive multiplier (1 matches the material value). Use **Rebake static
volume** after changing the emissive multiplier or static model. Enable **Show 3D
volume** or **Show volume slice** to inspect the result. The 3D view fills
the main screen and traverses occupied cells from the active scene camera;
move or rotate the camera to inspect the volume from another angle. It uses
the voxel occupancy alpha and stored radiance at mip 0 and draws cell edges.
Face direction does not tint the displayed color. The `Y slice` control
displays a horizontal cross-section in ImGui. Disable the existing SSGI effect when comparing
the contribution of Voxel GI alone.

The volume is baked on the first render and stays unchanged until an explicit
rebake. Both debug views refresh while open. Only the selected static scene
model contributes. The radiance bake does not sample scene lights or shadow
maps. The 64³ grid and standard mip filtering can leak light through thin
surfaces.
The bake also stores material albedo and normal volumes for DDGI light
evaluation at voxel ray hits.

## Test scene

Open **Render Test Scenes → Voxel GI Emission**. The scene loads
`data/model/VoxelGITest/scene.gltf`: a white room, red and blue emissive panels,
and a white divider. The test starts with emissive multiplier 8 and SSGI off.
Toggle **Voxel GI → Enabled** to compare the floor and walls with and without
the baked indirect contribution. **Show 3D volume** replaces the main view with
the voxel volume. The model source is generated by
`tools/generate_voxel_gi_test.py`.

The **Environment fill** slider controls the static diffuse fill captured at
bake time. Changing it or the emissive multiplier requires **Rebake static
volume**. Transparent glTF materials are excluded from the opaque volume.

The DDGI probe cache uses this volume as its radiance and visibility source.
See [DDGI](../DDGI/README.md) for the probe update and SSGI blend.
