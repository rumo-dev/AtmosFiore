# AtmosFiore 就活デモ

YMM4 プロジェクト: `AtmosFiore_就活デモ.ymmp`

## 技術ストーリー版（推奨）

`AtmosFiore_就活デモ_技術ストーリー.ymmp` は、先に作った版を残して追加した6分1秒の版です。冒頭18秒で完成画と代表的な表現を見せた後、次の5章で技術を説明します。

1. 完成画から逆算する：Indoor、PBRと環境照明、光源と影
2. 光を回す：SSGI、Voxel GI、DDGI
3. 空間を感じさせる：反射、動的な空、ボリュームフォグ
4. 画を整える：露出と順応、TAAとDLSS、HDR仕上げ
5. 描かずに成立させる：視錐台、メッシュレット、遮蔽判定

各技術を「完成結果 → 基準画像 → 左右比較 → 動画または関連技術」の順に見せます。テロップ、画像位置、拡大率、レイヤー、フェード、ループ動画はYMM4上で編集できます。比較用の暗い背景画像は `assets/` に同梱し、個別の撮影画像を参照しています。

## 最初の版

- 尺: 5分22秒 / 1920×1080 / 30fps / 48kHz
- 内容: 作品ロゴ → 完成シーン → 主要技術25項目 → 作品ロゴ
- 各項目: OFF画像4秒、ON画像4〜8秒。動画がある項目は最後の4秒にMP4を配置
- 音楽: `Data/Audio/BGM/game.wav` を3区間で使用

`Data/capture/screenshots/overview` の古いコンタクトシートは使用していません。個別の `*_off.png`、`*_on.png`、`video/*.mp4` を参照します。

YMM4の「ファイル → プロジェクトを開く」で `.ymmp` を選んでください。素材パスはこのPC上の絶対パスです。フォルダを移動した場合は、`build_ymmp.py` を再実行してパスを更新してください。

テロップと各カットはYMM4のタイムライン上で編集できます。BGMは既存のゲーム用音源を使っているため、応募先に合わせて音量と曲のつなぎ目を最終確認してください。
